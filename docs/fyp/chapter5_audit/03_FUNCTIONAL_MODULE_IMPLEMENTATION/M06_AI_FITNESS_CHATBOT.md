# M06 — AI fitness chatbot

**Status:** Implemented but Not Fully Verified. Mixed deterministic information retrieval and cloud Gemini generation. October 21 documentation records two deployed Gemini smoke replies without retained answer text. The November 16 release records authenticated/negative read probes without a Gemini answer request. See [AI service implementation](../04_CORE_TECHNOLOGY_IMPLEMENTATION/AI_FITNESS_CHATBOT.md) and [quality evaluation](../10_CORE_AI_EVALUATION/CHATBOT_EVALUATION.md).

**Interface:** Member enters Fitness Assistant, loads/acknowledges a current disclaimer, uses a typed question or a starter prompt, and sees thinking/retry states. Typed render cards cover progress, membership facts, branch/equipment facts, current coach options and read-only proposals. Saved Advice reads an account-scoped server list. Users can clear history, bookmark advice, and send a response-ID helpfulness rating. Cancelling a wait does not guarantee canceling an in-flight server request. `apps/mobile/lib/app/di/chatbot_factory.dart`, `apps/mobile/lib/features/chatbot/application/chat_bloc.dart:10–75,158–256`, `chatbot_screen.dart` and `assistant_reply_view.dart` under its presentation directory.

**Features and dependencies:** `FitnessAssistantContext` builds trusted local factual summaries for supported intents using scoped profile, workout and membership services. `FirebaseChatRepository` connects to `fitnessAssistantCommand` and the local conversation store. Server checks verified current active Member and organization, organization rollout and notice. Button visibility does not grant authority. Server-owned workout/branch data, current public coaching options and provider response are distinct inputs. A coaching suggestion hands off to the existing checkout path which revalidates details. It cannot create a booking, reserve a slot, send email or change a calendar. The outlined data-minimization and prompt/format protections are active in source.

**Persistence:** Conversation messages are held in the client Bloc. The authenticated callable stores disclosure revision, saved bookmark text (up to 50), response-ID ratings (up to 100) and the rate window in orgs/{org}/members/{uid}/chatbot/state. See `functions/src/modules/chatbot/chatbot-callable.ts:17–96`; client design in `apps/mobile/lib/infrastructure/firebase/firebase_chat_repository.dart`.
