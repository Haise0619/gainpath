# M13 — AI-powered trainer and content recommendation

**Status:** Implemented but Not Fully Verified, with narrow historical production acceptance. A controlled November 18 automatic Curl Tutorial run used Gemini and passed, with matching Rule-Based and Gemini first choice. Coach, Routine and every exercise/model combination need their own evaluation. The earlier synthetic POC ranking contract is a distinct experiment. See the [engine](../04_CORE_TECHNOLOGY_IMPLEMENTATION/AI_RECOMMENDATION_ENGINE.md) and [evaluation evidence](../10_CORE_AI_EVALUATION/RECOMMENDATION_EVALUATION.md).

Member Recommendations presents available published Tutorials, Routines and current Coach targets, method/why/details views and links that re-resolve current destinations. A personalized settings screen manages separate consent purposes. The existing Member Notification Center consumes typed, delivered notices and supports independent read/acknowledge/dismiss. Admin sees Insights/Recommendation detail, the Content Planner and explicit Member Outreach. Candidates can come from automatic recommendations or authored outreach. Planner suggestions prefill ordinary editable drafts; saving/publishing still goes through ordinary content authority. Mobile sources are `apps/mobile/lib/features/recommendation/presentation/member/`, `apps/mobile/lib/infrastructure/firebase/firebase_member_recommendations.dart` and `apps/mobile/lib/app/di/member_recommendation_factory.dart`. Admin sources include `apps/admin_web/lib/features/recommendation/presentation/admin/admin_ai_pages.dart`.
