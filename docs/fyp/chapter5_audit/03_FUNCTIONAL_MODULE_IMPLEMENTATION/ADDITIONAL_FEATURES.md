The group-class service validates a half-hour start/end grid and a maximum capacity of 60. Active registration counts remain synchronized with the Member schedule index. A confirmed change with existing participants also needs to preserve their overlap constraints. Attendance becomes available only once the class is completed. The Group Classes category values in source are Yoga, HIIT, Strength, Dance, Pilates and Other. See `functions/src/modules/group-classes/group-classes.ts:16,39–45,146–198,213–266`.
