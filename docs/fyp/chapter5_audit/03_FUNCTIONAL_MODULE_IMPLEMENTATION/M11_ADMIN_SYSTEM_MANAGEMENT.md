# M11 Admin account and system management

Admin Web operations group identity, membership, coaching, content, payments, settings and compliance. Its route gate uses a real AuthRepository and AuthBloc (`apps/admin_web/lib/app/admin_app.dart:79–156`). The responsive shell provides grouped navigation, account notifications, picker-driven drilldowns and sensitive-screen refresh handling (`app/shells/admin_shell.dart:317–433,451–635,1409–1470`). Client navigation and access checks improve UX. Firebase Rules and command services authorize data access.
