# M12 Admin dashboard and reporting

The Admin shell provides the business dashboard and scoped Reports categories, among them operations/commerce, fitness, coaching and engagement. It uses typed report gateways and Cubits to link range selections to specific aggregate sources. Overview loads the business summary, while other sections can defer queries to first use. Queries are keyed by scope and filters, stale results are checked and same-query in-flight reads can be shared. Loading, empty, partial and fatal-unavailable reporting states remain visible. See `apps/admin_web/lib/features/analytics/presentation/admin/reports_screen.dart`, `business_dashboard.dart`, `application/admin_reporting_cubit.dart`, and `infrastructure/firebase/firebase_admin_reporting_gateway.dart`.
