# 5.1.4.8 — Fitness Assistant AI and contextual personalization

## Request and data trust

`ChatBloc` holds the current conversation in memory, controls thinking/retry, and caps prompt length at 2,000 characters. `FirebaseChatRepository` first offers the question to scoped `FitnessAssistantContext`. Authorized factual responses can return locally with no provider use. If a callable is needed, the client submits organization/action/text and optionally a bounded branch hint or ephemeral booking option hint. Only a server-announced private-approved mode includes up to 12 recent history turns truncated to 2,000 characters each. The normal runtime default is public. `apps/mobile/lib/features/chatbot/application/chat_bloc.dart:158–220`, `fitness_assistant_context.dart`, `apps/mobile/lib/infrastructure/firebase/firebase_chat_repository.dart:130–203`.

Public provider payload includes current generic text, system instruction, allowed public tools, and where applicable public booking facts revalidated server-side. Public mode does not send private progress tool results or chat history and restricts certain heuristic personal disclosures; it cannot ensure arbitrary free text contains no personal data. The server resolves branch/availability/catalogue facts internally. In explicitly approved mode, prior text can be forwarded, and failure to scope the private progress tool rejects that retrieval. The validated progress contract can compare accepted server records with separately classified unverified device reports, but the ordinary client path does not necessarily transmit its device data. No training or fine-tuning is performed.

## Service stages and safety

| Stage | Implementation |
|---|---|
| Authorization and consent | Verified email, App Check, active Member in matching active organization, lifecycle/revocation check before and after scoped reads. Dedicated FYP identities are routed through FYP policy. Current revision of org disclaimer is required. Firestore `orgs/{org}/members/{uid}/chatbot/state` stores revision, rate counter, backstop last 50 bookmarks and last 100 ratings, without persisting the whole transcript. `functions/src/modules/chatbot/chatbot-callable.ts:17–69`. |
| Deterministic read first | Intent handlers answer branch/context, equipment inventory, authorized workout facts and Coach availability. A local reply can give profile and progress context without providing personal info to the provider. User input asking for personal fact without supporting reference receives a safe fact-limited reply. Scoped coach options/proposal tools perform reads; checked-out payments/bookings use a separate feature. `chatbot-callable.ts:70–235`. |
| Generation | Server uses configured `GEMINI_CHAT_MODEL` or `gemini-3.5-flash-lite` default and Secret Manager credential. 40-second overall deadline, 15 seconds per fetch, at most 5 provider iterations and 4 tool calls, 1,200 output tokens, temperature .2, ≤131,072 bytes transport body, ≤6,000 response text. Client callable and outer timeouts are 55 and 50 seconds. `functions/src/modules/chatbot/chatbot-service.ts:127–229`, repository constructor and request helper. |
| Tool and response validation | Registered read-only allowlist and argument validators; model tool output goes through a current scoped server read. Preserve follow-up parts for protocol; when a canonical tool answer is terminal, return it without a redundant next model turn. Reject non-STOP candidates, empty answer and oversized payloads. Server-generated telemetry logs numeric counts/model-version if present, not prompt/replies. `chatbot-service.ts:20–32,144–229`, `chatbot-callable.ts:239–245`. |
| Safety, uncertainty and quota | Prompt asks for English educational fitness scope, treats history/tool data as data, bars diagnosis, misuse, invented past results and external mutations. Regex and vetted replies run before/after generation. These are guardrails with incomplete coverage. Ten reply requests per Member/minute. 429 maps to capacity error, missing configuration/access to distinct state, timeout/network/unusable reply to retryable error. `chatbot-callable.ts:36–69,144–238`; `chatbot-service.ts:54–125,144–229`. |

**Sanitized illustrative request/response:** `{"organizationId":"example_org","action":"reply","text":"How do I warm up before a beginner bodyweight routine?"}`. Generic generation system prompt directs educational language, no fabricated personal history and no mutation. Illustrative reply shape `{"responseId":"example_reply","text":"Start with a few minutes of light movement and easy practice repetitions."}`. This text is a schematic example. Captured Gemini answers and user ratings are unavailable to cite as measured quality in this audit.
