## Status and authority

Exactly five status labels are used: **Implemented and live verified**, **Implemented but not live tested**, **Partially implemented**, **Mock-only**, **Not implemented**. A partial FR can contain a supported operation already live verified; the live column identifies that operation. “Implemented” describes software, not acceptance of broader normative outcomes. C/R/U/D means create/read/update/hard delete; deactivate, withdraw, cancel and remove-window are distinct operations.

Unless specified, paths below are under `orgs/{org}`. Firebase membership authority is `users/{uid}` plus `members/{uid}`; organization, role, active status and branch checks belong to the actual reader/command, not a mock object's display name. [Rules](../../firebase/firestore.rules), [indexes](../../firebase/firestore.indexes.json) and [Function exports](../../functions/src/index.ts) are source evidence; an index or read rule alone is not an implemented module.
