```powershell
flutter run -d <android-device-id> --target lib/main.dart --dart-define=WORKOUT_CLOUD_BACKUP_ENABLED=true --dart-define=APP_CHECK_IN_ENABLED=true
```

This command installs/launches on the chosen device; use only within an approved device scope. Build-only commands are in operations.
